# СТОИТ — сайт-гид по Москве

Минималистичный сайт о том, куда сходить в Москве: кафе, выставки, игры, прогулки и развлечения. От бесплатных до «особого случая». Чёрно-белая типографика с фиолетовым акцентом, русский и английский языки, адаптив под компьютер и телефон.

Главное отличие — **честная цена за конкретную услугу**. Не «средний чек на всё», а «за час игры», «за билет», «за вход», «средний чек» или «бесплатно». Цены разложены по уровням: бесплатно, до 300 ₽, 300–700 ₽, 700–1500 ₽, 1500+ ₽.

На телефоне сайт не заставляет листать одну длинную колонку: места идут по два в ряд, карточки компактные, фильтры свёрнуты, а каталог подгружается кнопкой «Показать ещё». Свежие идеи из источников — горизонтальная лента.

«План на сегодня» учитывает бюджет и компанию (друзья, свидание, один, с детьми), а места из последних семи дней не повторяет. У каждого места видно, на сколько человек оно рассчитано.

В каталоге можно выбрать сразу несколько категорий и настроений, а бюджет — ввести вручную (на человека). Счётчики рядом с фильтрами пересчитываются с учётом остальных фильтров.

## Быстрый запуск

Нужен Windows PowerShell 5.1 (уже есть в Windows) и `curl.exe` (тоже есть). Node.js, Python и установка пакетов не нужны.

1. Дважды кликните **`start.cmd`**.
2. Откроется <http://localhost:8787/>.
3. На телефоне в той же Wi-Fi: `http://<IP-компьютера>:8787/` — адрес печатается в консоли.

Если телефон не открывает сайт, разрешите порт 8787 в брандмауэре (PowerShell от администратора):

```powershell
New-NetFirewallRule -DisplayName "STOIT 8787" -Direction Inbound -LocalPort 8787 -Protocol TCP -Action Allow
```

Остановка — `Ctrl+C` в окне консоли.

### Ручной запуск

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools\serve.ps1 -Open
```

Порт можно изменить: `-Port 8788`.

## Как обновляются данные

- Сервер сам проверяет `data/feed.json`: если данным больше 20 часов, запускает сборщик в фоне.
- Кнопка «Обновить» на сайте запускает сборщик через `/api/refresh`.
- Для обновления без открытого сервера создайте задачу Windows:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools\install-daily-task.ps1
```

Задача `STOIT daily update` будет запускать `tools\refresh-all.ps1` каждый день в 09:00: лента обновляется ежедневно, каталоги OSM/Wikidata — раз в неделю. Удалить: добавьте `-Remove`.

Сборщик можно запустить вручную:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools\refresh-all.ps1
```

Каталоги OSM и Wikidata обновляются раз в неделю, лента — при каждом запуске. Флаги: `-NoTranslate` — без машинного перевода, `-MaxSignals 80` — сколько свежих карточек оставить, `-Force` — обновить каталоги принудительно. Повторный запуск в течение 6 часов берёт свежий кэш ленты, чтобы не ждать медленные RSS-мосты.

### Как выбираются материалы

Сборщик оставляет только места и события: кафе, бары, выставки, музеи, театры, парки, прогулки, игры, фестивали, экскурсии. Отсекаются новости, политика, спорт, светская хроника, реклама и другие города. Тема должна быть в заголовке, а не в случайном слове из текста.

Цена ищется в тексте: `300 ₽`, `300–500 рублей`, `бесплатно`, `вход свободный`. Единица цены определяется по контексту: билет, вход, час, с человека, средний чек.

Для карточек мест цены не выдумываются. Подтверждённые тарифы лежат в `data/prices.json`: сумма, единица, ссылка на официальный источник и дата проверки. Если тарифа нет в открытом источнике, карточка честно показывает «цена не указана», а не среднюю цифру по категории. На странице места видна ссылка «Проверить цену» и дата проверки.

### Автоматический поиск цен

После сборки каталога `collect.ps1` запускает поиск цен:

1. Берёт официальные сайты из OSM/Wikidata и ссылки, которые прямо есть в постах Telegram/Instagram.
2. Проверяет страницы «Билеты», «Цены», «Тарифы», «Меню».
3. Извлекает цену вместе с фразой-подтверждением и ссылкой на страницу.
4. Публикует в карточку только уверенные совпадения: точный взрослый билет, вход, час или тариф с официального сайта.
5. Спорные варианты складывает в `data/price-review.json` и не показывает как цену.
6. Цену из текста поста показывает только на карточке идеи с пометкой «цена из поста» или «цена из обсуждения». В «Только с ценой» такие цифры не попадают.

Ограничения: Instagram и Telegram часто не отдают ссылки и комментарии, а часть сайтов показывает цены только через JavaScript. Поэтому обсуждения учитываются, если цена или ссылка есть в тексте поста или в community-канале; полные комментарии через RSS обычно недоступны. Автоматический поиск не гарантирует цену для каждого места.

### Логотипы и фото

- В карточке каталога показывается логотип/иконка заведения. Если иконки нет или она не загрузилась, остаётся эмодзи.
- В большом блоке на странице места — только логотип. Фотографии вынесены вниз отдельной сеткой: 2 колонки на телефоне, 4 на компьютере, до 12 снимков, полноэкранный просмотр и ссылка на источник.
- Фото берутся с официального сайта, Wikidata/OpenStreetMap и Wikimedia; у галереи есть ссылка на источник.
- Найденные изображения хранятся в `data/media.json`, кэш — в `data/media-cache.json` (не публикуется). Лимиты: 24 сайта и 24 поста за обычный запуск, 72 и 72 — за недельный. Так ежедневное обновление остаётся быстрым, а глубокий сбор фотографий и цен идёт по воскресеньям. Кэш ответов — `data/price-cache.json`, TTL 7 дней. Для локального запуска без сети: `collect.ps1 -NoPriceSearch`.

### Проверка сайтов и закрытых мест

Перед публикацией сайт заведения проверяется автоматически:

- взрослый контент, казино, пиратские кинотеатры, страницы «домен продаётся» и «сайт закрыт» — домен снимается с карточки вместе с иконкой, фото и ценой с того же сайта;
- если страница сообщает, что место временно закрыто, и речь идёт обо всём заведении, а не об отдельном зале, катке или выставке, карточка не публикуется;
- если в OpenStreetMap у места стоит `opening_hours=closed`, оно тоже не попадает в каталог.

Ручные исключения лежат в `config/site-filters.json`: `blockedHosts` — домены, которые нельзя показывать, `closedPlaceIds` — закрытые места. Автоматическая проверка работает и без этого файла, список нужен для уже известных доменов и для закрытых мест без сайта.

Перевод на английский — через бесплатный MyMemory с кэшем и дневным лимитом. Если перевод недоступен, показывается оригинал: сайт не ломается.

## Ценовые уровни

| Уровень | Что это |
|---|---|
| Бесплатно | вход, прогулки, бесплатные игротеки |
| до 300 ₽ | кофе, перекус, час игры |
| 300–700 ₽ | ужин, кино, музей, активность |
| 700–1500 ₽ | билет в театр, смотровая, особый случай |
| 1500+ ₽ | большой повод: ресторан, Большой театр |

В каталоге есть отдельные фильтры по бюджету, категории и настроению. В карточке всегда написано, **за что** цена: «за первый час игры», «за билет», «за вход», «средний чек». По умолчанию показываются места с подтверждённой ценой; выключите «Только с ценой», чтобы открыть весь каталог, включая карточки без опубликованного тарифа.

## Язык и тема

- RU/EN переключается кнопкой в шапке, выбор сохраняется.
- Тёмная и светлая темы, по умолчанию тёмная.
- Сохранённые места хранятся в `localStorage`.
- «План на сегодня» собирает три остановки в выбранном бюджете.

## Офлайн и установка

Сайт кэшируется service worker'ом: после первого открытия работает без сети, данные берутся из кэша. На Android/Chrome и iOS/Safari можно добавить на домашний экран через меню браузера — это необязательно, сайт полноценно работает и так.

## Публикация в интернете

### GitHub Pages + Cloudflare Worker

Репозиторий: **публичный** (код и данные открыты, секретов внутри нет).
Сайт: **[stoit](https://maxddonich.github.io/stoit/)**. Технический адрес GitHub Pages содержит `maxddonich`; красивый адрес без него возможен только через свой домен.

Workflow `.github/workflows/update.yml`:
- ежедневно в 06:00 UTC (09:00 МСК) собирает ленту и деплоит Pages;
- каждое воскресенье в 03:00 UTC принудительно обновляет OSM/Wikidata;
- поддерживает ручной запуск `Run workflow`;
- **не коммитит `feed.json` каждый день** — лента попадает сразу в артефакт Pages;
- при сбое сборки публикуется последняя удачная версия.

Кнопка «Обновить сейчас» работает через **Cloudflare Worker** (`backend/`):
- Worker хранит GitHub-токен в секретах, не во фронтенде;
- лимит — **20 минут** на запуск и на IP;
- деплой — workflow **Deploy refresh Worker** (нужны секреты `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`);
- после деплоя добавьте URL Worker в **Settings → Variables → Actions** как `WORKER_URL`;
- следующий workflow сам подставит URL в `assets/config.js`;
- без Worker кнопка просто перечитывает уже опубликованную ленту.

Инструкция по Worker: `backend/README.md`.

### Любой статический хостинг

Загрузите `index.html`, `assets/`, `data/feed.json`, `manifest.webmanifest`, `sw.js`. Кнопка обновления на таком хостинге просто перечитывает `data/feed.json`; сами данные обновляйте локально через `tools\refresh-all.ps1` и загружайте новый файл (или используйте GitHub Actions).

## Важно

- Цены и наличие мест лучше сверять перед выходом — они собраны из открытых источников и могут меняться. Если тариф не подтверждён, карточка OSM/Wikidata показывает «цена не указана», а не выдуманную сумму.
- Ссылки ведут на первоисточники, партнёрских ссылок и рекламы нет.
- Telegram-мосты и MyMemory — бесплатные публичные сервисы, возможны лимиты. Сборщик рассчитан на мягкие ошибки и кэш.
- `data/seed.json` — ручная база, она не удаляется при сбое источников.
